# Ferrari F1 RACE TELEMETRY 桌面遥测面板

左下角赛车遥测面板，尺寸与壁纸左下角 MEDIA PLAYER 分区框 1:1 对齐
（实测物理 622×110，125% 缩放下逻辑 498×88），红黑赛博风格，八边形切角真透明。

## 显示内容

| 列 | 大数字 | 右侧小字 |
|---|---|---|
| CPU LOAD | 实时占用率 % | 逻辑核心数 |
| GPU LOAD | 实时占用率 %（NVIDIA，nvidia-smi） | 显卡温度 °C（不支持则 N/A） |
| MEMORY | 内存占用率 % | 已用/总容量 GB |
| NETWORK | ↓下载 ↑上传 | 单位（B/s · KB/s · MB/s 自动切换） |

底部红色动态曲线：CPU（亮红）+ GPU（橙红）最近 62 秒占用率走势。

## F1 旗语（右上角指示灯）

按 **CPU / GPU / 内存 各自的门槛**分别判定，取最严重的一个亮灯，并显示触发原因（如 `▲ YELLOW FLAG · RAM 88%`）：

| 指标 | 绿旗 | 黄旗 | 红旗 |
|---|---|---|---|
| CPU LOAD | < 70% | 70% ~ 89% | ≥ 90% |
| GPU LOAD | < 75% | 75% ~ 91% | ≥ 92% |
| MEMORY | < 85% | 85% ~ 92% | ≥ 93% |

> 内存门槛比 CPU/GPU 高，是因为 Windows 会把空闲内存拿去做文件缓存：
> 16G 机器日常占用 60%~75% 属于正常水位（任务管理器里显示"已用"包含缓存），
> 并不是真的快满了，所以不该亮黄旗。真正要担心的是 85% 以上、且"已提交"接近上限。

阈值可在 `%APPDATA%\FerrariF1Telemetry\settings.json` 中修改（单位：百分比）：

```json
"cpu_yellow": 70, "cpu_red": 90,
"gpu_yellow": 75, "gpu_red": 92,
"ram_yellow": 85, "ram_red": 93
```

改完重启面板（`关闭遥测面板.bat` → `启动遥测面板.bat`）即可生效。

## 日常使用

| 操作 | 说明 |
|---|---|
| 启动 | 双击 `启动遥测面板.bat`（无控制台窗口） |
| 关闭 | 双击 `关闭遥测面板.bat`，或点面板右上角 ✕ |
| 移动 | 固定位置，不可拖动（与壁纸框严格对齐） |
| 置顶 | 普通窗口，不置顶；被其他窗口挡住属正常 |

## 技术说明

- 全部指标使用 Windows 原生 API（GetSystemTimes / GlobalMemoryStatusEx / GetIfTable），
  无第三方依赖；GPU 通过 nvidia-smi 读取，无 NVIDIA 显卡时显示 N/A，不伪造数据
- 网络速率自动选取流量最大的物理网卡，不会因虚拟网卡/过滤层重复计数
- 单实例锁：重复启动不会出现第二个面板
- 配置目录：`%APPDATA%\FerrariF1Telemetry\`（位置、置顶、旗语阈值）

# Ferrari F1 RACE TIMELINE 桌面赛程面板

右下角赛程面板，尺寸与壁纸右下角 RACE TIMELINE 分区框 1:1 对齐
（实测物理 406×101，125% 缩放下逻辑 325×81，位于 (1191, 727)），
与左下角遥测面板同一套红黑赛博风格、八边形切角。

## 显示内容

| 位置 | 内容 |
|---|---|
| 左侧大数字 | 距下一场大奖赛的距离：`6D 19H 35M`（不足 1 天自动切换为 `19H 35M 08S`，开赛后 3 小时内显示 `RACE LIVE`） |
| 左侧小字 | 下一站名称与轮次（如 `LAS VEGAS GP · R21`）、开赛日期时间与当前时区（如 `22 NOV 11:00 · UTC+7`） |
| 右上 | 法拉利车队：当前排名 `P2`、总积分 `510`（SPA 车队积分榜） |
| 右下 | 法拉利两位车手：`HAM 261 P4 · LEC 249 P5`（车手积分 + 排名） |
| 底部 | 后续两站赛程：`UP NEXT 29 NOV QATAR GP · 06 DEC ABU DHABI GP` |

右上角指示灯：`● SYNC` 表示数据已同步，`● OFFLINE` 表示当前拉取失败、正在用本地缓存显示。

## 数据来源

- 赛历与积分：Jolpica-F1（Ergast 官方继任者，免费、无需 API Key）
  - `https://api.jolpi.ca/ergast/f1/<赛季>/races.json`
  - `.../driverstandings.json`、`.../constructorstandings.json`
- 每 30 分钟刷新一次；断网时读取本地缓存 `%APPDATA%\FerrariF1Timeline\cache.json`，
  倒计时仍按缓存赛历正常走，绝不显示伪造数据
- 时间换算与时钟组件共用同一份城市时区配置：
  读取 `%APPDATA%\FerrariF1WidgetCompact\settings.json` 里的 `utc_offset`，
  所以只要在时钟组件里换城市，赛程时间会自动跟着变

## 日常使用

| 操作 | 说明 |
|---|---|
| 启动 | 双击 `启动赛程面板.bat`（无控制台窗口） |
| 关闭 | 双击 `关闭赛程面板.bat`，或点面板右上角 ✕ |
| 移动 | 固定位置，不可拖动 |
| 刷新 | 右键面板 → 立即刷新 |
| 置顶 | 普通窗口，不置顶 |

## 技术说明

- 纯 Python 标准库 + tkinter，无第三方依赖
- 八边形窗口区域（SetWindowRgn）实现真透明切角，与壁纸框严丝合缝
- `WS_EX_TOOLWINDOW`：不进任务栏、不进 Alt+Tab
- 单实例锁（命名互斥体），重复启动不会开出第二个面板
- 网络请求在后台线程执行，界面不会卡顿；异常写入 `%APPDATA%\FerrariF1Timeline\error.log`
