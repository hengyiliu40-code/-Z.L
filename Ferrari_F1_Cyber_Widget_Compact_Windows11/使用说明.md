# Ferrari F1 Cyber Widget · 桌面镶嵌版（Compact）

Windows 11 桌面组件：时钟 + 天气，像壁纸的一部分一样"钉"在桌面上，不是普通程序窗口。

## 特性
- 24 小时实时时钟 + 日期（大号时分 + 右上角秒数），**按所选城市时区显示**
- 实时天气：温度、体感温度、湿度、天气状况（Open-Meteo，免 API Key）
- **精确镶嵌**：尺寸 210×241（逻辑像素）正好等于壁纸右上角 "SYSTEM INFO AREA" 分区框
- **八边形切角真实透明**：用 Windows 窗口区域（SetWindowRgn）把窗口裁成八边形，切角处直接透出壁纸，不是黑块
- **位置固定，不可拖拽**
- 不进任务栏、不进 Alt+Tab，按 Win+D 显示桌面也不会消失
- 开机静默自启，无黑框闪烁

## 日常使用
| 操作 | 说明 |
|---|---|
| 启动 | 双击 `启动 Ferrari 桌面组件.bat`（无控制台窗口） |
| 关闭 | 双击 `关闭组件.bat`（也可以点组件右上角 × 或按 Esc） |
| 换城市 | 在组件上**右键**或**双击**，输入城市英文名（如 Shanghai、Tokyo）—— 时钟时区会跟着城市变 |
| 移动 | 已禁用拖拽。如果换了壁纸/分辨率需要调位置，改脚本顶部 `RIGHT_MARGIN` / `TOP_MARGIN` |

默认城市：Bangkok（曼谷，UTC+7）。

## 开机自启
启动文件夹里已放置自启脚本，登录 Windows 后会自动运行：

```
%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\Ferrari F1 Cyber Widget.vbs
```

- 想**取消**开机自启：删除上面这个 `Ferrari F1 Cyber Widget.vbs` 文件即可
- 脚本会自动挑选本机已安装的 Python 3（3.10–3.14），不写死版本号

## 配置文件
```
%APPDATA%\FerrariF1WidgetCompact\settings.json   # 城市、坐标
%APPDATA%\FerrariF1WidgetCompact\widget.pid      # 运行中的进程号（关闭脚本用）
%APPDATA%\FerrariF1WidgetCompact\error.log       # 出错时才会生成
```

想恢复默认（右上角、曼谷）：删除 `settings.json` 后重新启动组件。

## 环境要求
- Windows 10/11
- Python 3.9+（安装时勾选 Add Python to PATH），需要带 tkinter 的官方版本
- 只用标准库，无需 pip 安装任何第三方包
- 天气需要联网；时钟离线可用

## 路径变动注意
如果把整个文件夹移动到别的位置，需要同步改两处：
1. 自启脚本 `.vbs` 里的 `script` 路径
2. 重新双击一次 `启动 Ferrari 桌面组件.bat`（它按自身目录找脚本，无需修改）

## 打包成 EXE（可选）
双击 `打包为EXE.bat`（需联网），会在 `dist` 生成独立 EXE。
注意：PyInstaller 打包的 EXE 容易被杀毒软件误报，桌面组件推荐直接用源码版运行。
